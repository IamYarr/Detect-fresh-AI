# 🍏 Детектор свежести овощей и фруктов 🍅

Прототип локальной системы машинного зрения для оценки качества продуктов питания. Проект построен на основе легковесной нейросети **MobileNetV3-Small** (PyTorch) и использует инструменты компьютерного зрения (OpenCV) для анализа фотографий.

## 🗂 Классификация

Система автоматически делит продукцию на 3 класса:
*   🥦 **FRESH** — Идеальное состояние, без дефектов (годен к продаже).
*   🍋 **MINOR_DEFECT** — Лёгкие признаки порчи: мелкие пятна, помятости (годен к уценке).
*   🥔 **SPOILED** — Явная порча: плесень, гниль, сильная деформация (не годен).

## 🛠 Зависимости и установка

📦 Все необходимые библиотеки для работы (PyTorch, OpenCV, Albumentations и др.) жестко зафиксированы и указаны в файле `requirements.txt`. 

Разверните виртуальное окружение и установите их командой:
```powershell
pip install -r requirements.txt
```
