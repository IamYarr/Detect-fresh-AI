# 🍅 Контроль свежести овощей и фруктов (Computer Vision)

Прототип локальной системы машинного зрения для оценки качества и классификации продуктов питания. Система определяет состояние продукта на фотографии, возвращает предсказанный класс и уровень уверенности (confidence). При уверенности ниже заданного порога срабатывает механизм `[MANUAL_REVIEW]` для перевода продукта на ручную контроль.

Проект выполнен в рамках задания «Свежесть овощей и фруктов». По умолчанию используется архитектура MobileNetV3-Small, но возможна интеграция любой другой модели из `torchvision`.

## 📦 Классификация
Система классифицирует продукцию на 3 категории:
1. 🍏 `FRESH` — Без дефектов, годен к продаже.
2. 🍋 `MINOR_DEFECT` — Легкие признаки порчи (мелкие пятна, мягкость). Годен к уценке.
3. 🥔 `SPOILED` — Явная порча (плесень, гниль). Не годен к продаже.

## ⚙️ Архитектура проекта

*   **`prepare_data.py`**
    Утилита для балансировки датасета. Забирает исходные фотографии, присваивает им уникальные UUID и распределяет в пропорции 70/15/15 по директориям `train`, `val` и `test`.
*   **`dataset.py`**
    Пайплайн загрузки данных. Формирует батчи и применяет аугментации (повороты, изменение яркости, размытие) через библиотеку Albumentations.
*   **`model.py`**
    Модуль инициализации. Выполняет загрузку базовых весов (Transfer Learning) и адаптацию классификатора под целевые классы.
*   **`train.py`**
    Основной цикл обучения. Реализует логику early stopping, сохраняя веса лучшей модели по результатам валидации после каждой эпохи.
*   **`inference.py`**
    Скрипт предсказания. Вычисляет вероятности посредством Softmax, динамически масштабирует шрифты при отрисовке плашек на фото и формирует `inference_results.json`. При confidence < 0.65 товару присваивается флаг `[MANUAL_REVIEW]`.

## 🚀 Развертывание и работа с данными

Необходимые зависимости зафиксированы в `requirements.txt`. Рекомендуется выполнять установку в изолированном виртуальном окружении (venv, conda или аналоги).

### 1. Подготовка датасета
Перед началом обучения необходимо структурировать исходные данные:
1. Создайте директорию `Resources/raw_img/`.
2. Внутри создайте три папки в строгом соответствии с целевыми классами: `FRESH`, `MINOR_DEFECT` и `SPOILED`.
3. Поместите неструктурированные фотографии в соответствующие папки.
4. Выполните ***prepare_data.py***

Скрипт автоматически сформирует итоговую структуру в `Resources/img/` с необходимым разделением на выборки.

### 2. Обучение
Запустите тренировочный цикл ***train.py***. Веса лучшей модели будут сохранены в `Resources/models/mobilenetv3_freshness.pth`.


### 3. Инференс
Для тестирования модели на отложенной выборке и генерации результатов выполните ***inference.py***

## 📊 Результаты работы
Результаты сохраняются в `Resources/results/`:
- Изображения с отрисованным предсказанным классом и показателем confidence.
- Структурированный `inference_results.json` для интеграции с внешними системами.
